# Electronics Service Management System

Aplikasi berbasis web untuk membantu pengelolaan operasional usaha jasa perbaikan perangkat elektronik.

## Tentang Proyek

Electronics Service Management System dikembangkan untuk menggantikan pencatatan servis elektronik secara manual dengan sistem digital yang terstruktur.

Aplikasi ini dirancang untuk membantu pengelola dalam mencatat pelanggan, perangkat yang diterima, diagnosis kerusakan, estimasi biaya, proses perbaikan, pembayaran, pengambilan perangkat, dan garansi.

Proyek ini dibangun berdasarkan proses bisnis nyata pada usaha jasa servis elektronik.

## Fitur Utama

- Autentikasi pengguna.
- Pengelolaan data pelanggan.
- Pencatatan servis satu atau beberapa perangkat.
- Diagnosis dan estimasi biaya per perangkat.
- Pengelolaan persetujuan pelanggan.
- Pemantauan status pengerjaan.
- Pencatatan kebutuhan komponen.
- Pengelolaan DP dan pembayaran.
- Alokasi pembayaran untuk beberapa perangkat.
- Pengembalian DP.
- Pengambilan perangkat secara bertahap.
- Pengelolaan garansi.
- Penyimpanan bukti pemberitahuan pelanggan.
- Nota digital dan laporan transaksi.

## Teknologi

- **Backend:** PHP – Laravel
- **Database:** MySQL
- **Frontend:** Blade + Bootstrap
- **Version Control:** Git & GitHub
